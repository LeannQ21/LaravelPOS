# Laravel POS Application

## IT0049 Web System Technologies

### Technical Formative Assessment 5

**From Zero to Four Pages Again Your First Laravel Application**

**Created by:** Leann Marie S. Querubin

A Laravel-based Point of Sale application demonstrating routes, controllers, Blade views, and static PHP arrays.

## Features

- Home page
- About page
- Customer Accounts page
- User Accounts page
- Navigation between all pages
- Static customer records
- Static user records
- Blade `@foreach` loops for displaying records

## Pages

- `/` - Home page
- `/about` - About page
- `/customers` - Customer Accounts page
- `/users` - User Accounts page
